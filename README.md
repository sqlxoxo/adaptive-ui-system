# Adaptive Task Management System

Інформаційна система керування задачами (Task Management System) з адаптивним користувацьким інтерфейсом (Adaptive UI/UX). Система динамічно підлаштовує свою складність та відображення компонентів під рівень навичок користувача (Novice або Expert) на основі збору та аналізу поведінкових метрик у реальному часі.

---

## 🚀 Основний Функціонал

1. **Адаптивна дошка задач (Kanban)**:
   - Створення задач, редагування статусу (**To Do**, **In Progress**, **Done**), визначення пріоритетів та видалення.
   - Динамічні розміри елементів керування залежно від рівня навичок користувача.

2. **Модуль трекінгу поведінки (Telemetry Tracking)**:
   - Контекстний JS-скрипт фоново відстежує дії користувача:
     - Кількість помилок валідації (наприклад, спроби зберегти задачу без імені).
     - Час блукання мишкою (mouse hover time) над робочими зонами без взаємодії (сигнал вагання).
     - Час, витрачений на створення першої задачі (таймер швидкості адаптації).
     - Частота використання гарячих клавіш або швидких дій системи.
   - Телеметрія автоматично синхронізується з сервером через POST-ендпоінт `/api/telemetry` кожні 12 секунд.

3. **Інтелектуальний бекенд аналізу**:
   - Розрахунок інтегрального індексу майстерності користувача (Skill Score від 0 до 100).
   - Автоматична класифікація користувача:
     - **Novice (Новачок)**: Для тих, у кого низька активність швидких дій, висока кількість помилок валідації або часті вагання мишки.
     - **Expert (Експерт)**: Для тих, хто діє чітко, швидко виконує перші кроки та використовує гарячі клавіші.

4. **Гнучкий адаптивний інтерфейс (Adaptive UX/UI)**:
   - **Режим Novice**: спрощена дошка, відсутність дратівливих дрібних деталей, великі очевидні кнопки, інтерактивний покроковий гід (`OnboardingGuide`) та спливаючі підказки (tooltips) біля кожної колонки.
   - **Режим Expert**: компактний та функціональний вигляд, автоматична активація розширеної аналітики (інтерактивні графіки трендів), панель швидких гарячих клавіш (`Expert Quick Actions Panel`), розширений пошук та фільтрація задач за пріоритетами.

---

## 🛠️ Технологічний Стек

- **Frontend**: React (v19), Vite, Tailwind CSS, Lucide-React Icons.
- **Node Fullstack Server**: Express (v4), TypeScript, `db.json` як локальний файл бази даних.
- **Python Backend (Alternative/Reference)**: Python, FastAPI, SQLAlchemy ORM, СУБД SQLite. Побудовано чітку модель евристичного аналізу телеметрії `rules.py`.

## 🏃‍♂️ Інструкція із запуску проєкту

Проєкт надає готові рішення як на базі Node.js Fullstack (React + Express), так і на базі Python (FastAPI).

### Варіант 1: Запуск Node.js Fullstack (Основний)

Цей варіант запускає React інтерфейс та інтегрує його з Express-сервером, включаючи підтримку розпізнавання телеметрії та збереження результатів.

1. **Встановлення залежностей**:
   ```bash
   npm install
   ```

2. **Запуск у режимі розробки (Development)**:
   ```bash
   npm run dev
   ```
   *Додаток буде доступний на порту:* `http://localhost:3000`

3. **Побудова та запуск у Production**:
   ```bash
   npm run build
   npm start
   ```

---

### Варіант 2: Запуск альтернативного Python-бекенду (FastAPI)

Якщо ви бажаєте використовувати у якості API-сервера FastAPI та SQLAlchemy (SQLite):

1. **Перейдіть до директорії з Python-файлами та встановіть залежності**:
   ```bash
   cd python_backend
   pip install fastapi uvicorn sqlalchemy pydantic
   ```

2. **Запустіть FastAPI сервер через Uvicorn**:
   ```bash
   uvicorn main:app --host 0.0.0.0 --port 8000 --reload
   ```
   *Локальний інтерфейс API-документації буде доступний за адресою:* `http://localhost:8000/docs`

## 🎹 Гарячі клавіші Експерта (Expert Shortcuts)
При переході на рівень **Expert** (або при використанні Симулятора розробника на екрані) стають активними такі комбінації клавіш:
- **`N`** — Відкрити модальне вікно створення нової задачі.
- **`S`** — Одразу сфокусуватись на полі пошуку задач.
- **`C`** — Швидко очистити всі виконані задачі (статус `Done`).
- **`Esc`** — Закрити будь-яке відкрите модальне вікно.
